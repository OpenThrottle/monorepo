# OpenClaw — Naming and Official Sources

Use **OpenClaw** only (current product name). Former names: ClawdBot, MoltBot.

## Official sources

| Resource    | URL                                                                  |
| ----------- | -------------------------------------------------------------------- |
| Website     | [openclaw.ai](https://openclaw.ai)                                   |
| GitHub repo | [github.com/openclaw/openclaw](https://github.com/openclaw/openclaw) |
| Docs        | [docs.clawd.bot](https://docs.clawd.bot)                             |

## For install and Docker

- **Use:** `https://github.com/openclaw/openclaw` for cloning and [docs.clawd.bot](https://docs.clawd.bot) for install/Docker steps (e.g. [docs.clawd.bot/install/docker](https://docs.clawd.bot/install/docker)).
- **Avoid:** `clawdbot/clawdbot` and `clawd.bot` install URLs; use the openclaw repo and docs.clawd.bot for Docker setup.
