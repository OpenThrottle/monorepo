# Round 3: Naming Candidates Without the “Kit” Suffix

Round 3 focuses on **avoiding the “Kit” suffix** while keeping names that (1) hint at purpose (CMS vs plans/knowledge base), (2) support one coherent root for X, GitHub, and NPM, and (3) stay distinct. Availability is **not** checked here—run the same availability workflow before shortlisting.

See [naming-criteria-and-availability.md](./naming-criteria-and-availability.md) for criteria and [naming-final-convention-and-choices.md](./naming-final-convention-and-choices.md) for current choices (EditKit / VectorKit). Round 2 (many Kit-based options): [naming-round-2-candidates.md](./naming-round-2-candidates.md).

---

## ex-RocketCMS (CMS / product) — Round 3 (no Kit)

Editorial, content, and publishing metaphors without “Kit.”

| Candidate       | Rationale |
|-----------------|-----------|
| **EditForge**   | Editing + building; Forge pattern. Carried from Round 2. |
| **CopyDesk**    | Editorial “copy desk” metaphor. Short; clear for content teams. |
| **Manuscript**  | Long-form content and publishing. Single word; strong brand. |
| **Inkwell**     | Writing/editing metaphor. Distinct; single word. |
| **PublishDesk** | Publishing + desk (workspace). Clear purpose. |
| **ContentDesk** | Content + desk. Literal; easy to understand. |
| **DraftDesk**   | Drafts + desk. Fits editorial workflow. |
| **StoryDesk**   | Stories/content + desk. Evokes narrative and content. |
| **PageForge**   | Pages/content + building. Forge pattern. |
| **TypeForge**   | Typography/content + forge. Niche but clear. |

---

## ex-Cortex (plans / knowledge base) — Round 3 (no Kit)

Plans, memory, context, and search metaphors without “Kit.”

| Candidate        | Rationale |
|------------------|-----------|
| **MemoryForge**  | Memory + building. Strong for knowledge base. Carried from Round 2. |
| **ContextForge**| Context (MCP, LLM) + building. Forge pattern. |
| **RecallForge** | Recall = retrieving knowledge; Forge = building. Evokes search and plans. |
| **IndexForge**  | Index = structure for finding things. Clear for knowledge base. |
| **SemanticForge**| Semantic search/embeddings. On-the-nose for vector stack; slightly long. |
| **PlanForge**   | Plans + building. Direct and clear. |
| **TraceForge**  | Trace = following plans/tasks. Forge pattern. |
| **Atlas**       | Map of knowledge. Single word; strong metaphor. May be taken. |
| **Lens**        | View into knowledge/context. Single word; short. |
| **ContextDesk** | Context + desk. Alternative to Forge pattern. |
