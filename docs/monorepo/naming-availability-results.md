# Availability Check Results for Naming Candidates

Per [naming-criteria-and-availability.md](./naming-criteria-and-availability.md), we check **X (Twitter) handle**, **GitHub organization**, and **NPM scope** so that one coherent root can be used everywhere.

**How to read:** GitHub was checked by visiting `https://github.com/<root>` (404 = likely available; 200 = taken). X and NPM require manual checks: visit `https://twitter.com/<handle>` and `https://www.npmjs.com/org/<scope>` (or try claiming when creating an org / publishing).
