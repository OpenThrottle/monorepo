Uses the upload-and-decompose route. The PRD used on screen must be a fictional
one shipped with the demo seed — never a real internal document.

## Beats

| t    | on-screen action                                            | narration                                                              |
| ---- | ----------------------------------------------------------- | ---------------------------------------------------------------------- |
| 0:00 | A fictional two-page PRD open in the browser.               | You already wrote the spec. You should not have to write the plan too. |
| 0:07 | Navigate to `/plans/upload-decompose`.                      | Drop it in here.                                                       |
| 0:12 | Drag the PRD file onto the drop zone; the filename appears. | Any document you already have. A spec, a ticket, a wall of notes.      |
| 0:21 | Click **Decompose**; a progress state shows.                | It reads the whole thing and pulls out the actual work.                |
| 0:29 | Proposed plan and task list render, editable.               | You get a draft plan with tasks, in order, before anything is saved.   |
| 0:38 | Edit one task title; delete one task.                       | Fix what it got wrong. It will get something wrong.                    |
| 0:46 | Click **Save**; plan detail loads with the accepted tasks.  | Then save it, and the agents have somewhere to start.                  |
| 0:54 | Outro card.                                                 |                                                                        |
