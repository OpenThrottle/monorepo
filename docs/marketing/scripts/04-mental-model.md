The only Season 1 short that teaches a vocabulary rather than a click-path. Risk:
it turns into four definitions read aloud. The action column carries the weight —
each term is shown, not described.

## Beats

| t    | on-screen action                                | narration                                                                           |
| ---- | ----------------------------------------------- | ----------------------------------------------------------------------------------- |
| 0:00 | Plan detail open, tasks visible.                | Four words, and then you know the whole system.                                     |
| 0:05 | Highlight the plan header.                      | A plan is a goal with an ordered list of work under it.                             |
| 0:12 | Highlight one task row.                         | A task is one unit of that work. It has a status and exactly one owner at a time.   |
| 0:21 | Navigate to `/notes`, open a seeded note.       | A note is context. Something you learned that you want the agent to find later.     |
| 0:31 | Navigate to `/projects`, open a seeded project. | A project is a checkout on disk. It tells the agent where the code actually is.     |
| 0:41 | Back to the plan; show its project badge.       | Plans point at a project. Tasks live under plans. Notes are searchable by anything. |
| 0:50 | Hold on the plan.                               | That is the whole vocabulary.                                                       |
| 0:54 | Outro card.                                     |                                                                                     |
