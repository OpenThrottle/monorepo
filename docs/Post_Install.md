# Post Installation

```bash
👀 👀 👀 setup.sh 👀 👀 👀

Now copy 'OPENTHROTTLE_MCP_AUTH_TOKEN' and 'OPENTHROTTLE_WORKER_GRAPHQL_AUTH_TOKEN'" from your local '.bootstrap-secrets.local' and replace the values in:"

- .env
- applications/openthrottle-server/.env

And lastly follow run 'pnpm run setup:mcp-instructions' to get the "OpenThrottle MCP" installed globally.
```
