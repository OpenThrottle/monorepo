# @openthrottle/graphql-codegen

GraphQL code generation presets and utilities for TypeScript projects.

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/graphql-codegen
```

**npm:**

```bash
npm install @openthrottle/graphql-codegen
```

**yarn:**

```bash
yarn add @openthrottle/graphql-codegen
```
