# @openthrottle/nestjs-tester

A package for testing NestJS via a consumer application. This package provides testing utilities and helpers for writing integration tests and testing NestJS modules in a consumer application context.

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/nestjs-tester
```

**npm:**

```bash
npm install @openthrottle/nestjs-tester
```

**yarn:**

```bash
yarn add @openthrottle/nestjs-tester
```
