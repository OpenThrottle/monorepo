# @openthrottle/nestjs-bullmq-board

BullMQ board UI module for NestJS applications to monitor and manage job queues. This package provides a web-based dashboard for monitoring BullMQ queues, jobs, and workers in your NestJS applications.

> [!Important]
> This package is based on [bull-board](https://github.com/felixmosh/bull-board/tree/master/packages/nestjs)

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/nestjs-bullmq-board
```

**npm:**

```bash
npm install @openthrottle/nestjs-bullmq-board
```
