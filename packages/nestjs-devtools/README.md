# @openthrottle/nestjs-devtools

NestJS DevTools module for enhanced development experience. This package provides development tools and utilities for debugging and monitoring NestJS applications.

**Resources:**

- https://docs.nestjs.com/devtools/overview

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/nestjs-devtools
```

**npm:**

```bash
npm install @openthrottle/nestjs-devtools
```

**yarn:**

```bash
yarn add @openthrottle/nestjs-devtools
```
