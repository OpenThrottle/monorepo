# @openthrottle/nestjs-throttler

Rate limiting module for NestJS applications. This package provides throttling and rate limiting capabilities to protect your API endpoints from abuse and ensure fair resource usage.

**Resources:**

- https://docs.nestjs.com/security/rate-limiting

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/nestjs-throttler
```

**npm:**

```bash
npm install @openthrottle/nestjs-throttler
```
