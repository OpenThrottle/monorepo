# @openthrottle/nestjs-express

NestJS Express integration and utilities for HTTP apps.

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/nestjs-express
```

**npm:**

```bash
npm install @openthrottle/nestjs-express
```

**yarn:**

```bash
yarn add @openthrottle/nestjs-express
```
