# @openthrottle/react-router-chat

Library scaffold for React Router chat UI, loaders, and hooks in OpenThrottle applications.

## Installation

**In this monorepo:** add `"@openthrottle/react-router-chat": "workspace:*"` to the consuming package’s `package.json`, then run `pnpm install` from the repository root.

This package is **private** to the workspace and is not published to the public registry.
