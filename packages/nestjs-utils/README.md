# @openthrottle/nestjs-utils

Utility functions and helpers for NestJS applications. This package provides reusable utilities, decorators, and helper functions that can be used across NestJS projects.

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/nestjs-utils
```

**npm:**

```bash
npm install @openthrottle/nestjs-utils
```

**yarn:**

```bash
yarn add @openthrottle/nestjs-utils
```
