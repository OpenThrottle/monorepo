# @openthrottle/nestjs-redis

A module for using Redis in a NestJS application. This package provides Redis integration for caching, session storage, and other Redis-based features in your NestJS applications.

## Installation

Install with your preferred package manager:

**pnpm:**

```bash
pnpm add @openthrottle/nestjs-redis
```

**npm:**

```bash
npm install @openthrottle/nestjs-redis
```
