**OpenThrottle** is a _plans knowledge base_ for agentic engineering: Postgres-backed storage, semantic search, and MCP servers that keep plans, tasks, and repo docs queryable from your editor.

Know what you're building, what's in flight, and what already shipped—without digging through chat history. Use **ask OT** for answers, run agentic work with **Ralph**, and track momentum on the developer dashboard.

Git is the history of code; OpenThrottle is the history of work—intent, status, and outcomes.

**Includes:** plans and tasks · semantic search · docs ingest · Ralph loops · Cursor/VS Code MCP · GraphQL API · developer portal · Nx monorepo with publishable packages.
