# AGENTS.md — `skills/`

> Tier context for this repo's custom agent skills. Workspace-wide guidance: [root AGENTS.md](../AGENTS.md).

This folder holds the **custom skills we author** — both Shiftsmart-wide workflow skills (the `github-*` family: `github-branch`, `github-commit`, `github-create-issue`, `github-merge`, `github-pull-request`, `github-squash`, `github-summarize`) and repo-specific ones like [`pubsub-local-setup/`](./pubsub-local-setup/) for the local GCP Pub/Sub emulator workflow (see also [`docs/PubSub-Setup.md`](../docs/PubSub-Setup.md)). Other Shiftsmart repos install these via `npx skills add shiftsmartinc/shiftsmart --agent universal`.

## Where skills live

- **`skills/` (this folder) — authored skills.** Hand-written, committed, PR-reviewed. Any repo can have its own.
- **`.agents/skills/` — the merged SSOT view** every supported universal agent tool reads natively. Ownership by node type: **real directories** are external skills installed via `npx skills add … --agent universal` and tracked in [`skills-lock.json`](../skills-lock.json) — never hand-edit them; **symlinks** are this repo's `skills/*`, generated by the sync. A name collision between the two is an error.
- **Agent folders (`.claude/skills/`) — generated, never authored.** Fan-out for the few tools that don't read `.agents/skills/` natively (currently only Claude Code); configurable per repo via the `AGENT_SKILL_DIRS` env var.

The whole layout is built, validated (`--check`, run in CI), and torn down by the [`shiftsmart-skill-sync`](./shiftsmart-skill-sync/SKILL.md) skill — installable into any shiftsmartinc repo. Skills travel between repos via `npx skills add shiftsmartinc/shiftsmart --agent universal`, never via cross-repo symlinks.

## Sharing across Shiftsmart repos

Skills can be installed across Shiftsmart repositories with the `npx skills` CLI documented in [`docs/Skills.md`](../docs/Skills.md):

```bash
# See what's available
npx skills list

# Add a skill from a repo (always --agent universal: install only to .agents/skills/)
npx skills add <owner>/<repo> --skill <skill_name> --agent universal

# Install our shared skills into another Shiftsmart repo
npx skills add shiftsmartinc/shiftsmart --skill github-pull-request --agent universal

# Keep them up to date
npx skills update
```

## Conventions

- Author repo-specific skills **here** in `skills/`; let `.agents/skills/` be the managed home for external skills.
- Each skill is its own directory containing a `SKILL.md`. Keep it focused and self-contained.
- **Never use relative links that point outside the skill's directory.** Skills are copied into other repos on install, so a `../../docs/...` link dangles there. Link within the skill relatively; link everything else by absolute URL (e.g. `https://github.com/shiftsmartinc/shiftsmart/blob/main/docs/PubSub-Setup.md`) — anyone who installed the skill has repo access already.
- When a skill overlaps with docs (e.g. the Pub/Sub setup), cross-link the two so agents can find either entry point.
