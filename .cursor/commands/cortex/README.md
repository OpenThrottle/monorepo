# Cortex Cursor commands

**Central reference:** `.cursor/rules/commands/cortex.mdc` — what Cortex is, when to use it, all MCP tools, and this command list.

| Command                  | Purpose                                                                         |
| ------------------------ | ------------------------------------------------------------------------------- |
| `/cortex/ask`            | Answer a question using Cortex (semantic search, list by status, list sources). |
| `/cortex/pending`        | List plans with status `pending`.                                               |
| `/cortex/list-by-status` | List plans by status (e.g. in_progress, completed).                             |
| `/cortex/list-sources`   | List plans/sources in the knowledge base.                                       |
| `/cortex/create-plan`    | Create a new plan (and optional initial tasks).                                 |
| `/cortex/planning-mode`  | Turn an idea or rough notes into a plan + tasks.                                |
| `/cortex/edit-task`      | Edit an existing task.                                                          |

Schema and DB setup: `databases/cortex/README.md`.
