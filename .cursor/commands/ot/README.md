# OpenThrottle (OT) Cursor commands

**Central reference:** `../../rules/commands/openthrottle.mdc` — what OT is, when to use it, all available MCP tools, and this command list.

| Command              | Purpose                                                                     |
| -------------------- | --------------------------------------------------------------------------- |
| `/ot/ask`            | Answer a question using OT (semantic search, list by status, list sources). |
| `/ot/pending`        | List plans with status `pending`.                                           |
| `/ot/list-by-status` | List plans by status (e.g. in_progress, completed).                         |
| `/ot/list-sources`   | List plans/sources in the knowledge base.                                   |
| `/ot/create-plan`    | Create a new plan (and optional initial tasks).                             |
| `/ot/planning-mode`  | Turn an idea or rough notes into a plan + tasks.                            |
| `/ot/edit-task`      | Edit an existing task.                                                      |

Schema and DB setup: `../../../databases/README.md`.
