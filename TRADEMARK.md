## The marks

**"OpenThrottle"** (the word mark) and the OpenThrottle logo (together, the
"Marks") are trademarks of **Matthew Scholta**. The Marks identify the
OpenThrottle project and its official distributions and services.

This policy governs use of the Marks. It is **separate from the software
license**: the code is open source under the [Apache License, Version 2.0](./LICENSE.md),
but — as Apache-2.0 **§6** makes explicit — an open-source code license does
**not** grant any right to use the licensor's trademarks. You can fork the code
freely; you cannot freely use the name or branding.

## Status

The "OpenThrottle" word mark is the subject of a **pending U.S. trademark
application** (USPTO, International Class 9, filed intent-to-use under §1(b)). The
mark is **not yet registered**. Until registration issues, refer to it with the

registers.

## Why a trademark policy

When the code is permissively licensed and freely forkable, the brand is what
distinguishes the official project from forks and third parties. A clear
trademark policy lets the community reuse and build on the code with confidence
while keeping the OpenThrottle name a reliable signal of what is official.

## Acceptable use — no permission needed

- **Fork, modify, and redistribute the code** under Apache-2.0.
- **Refer to OpenThrottle factually** (nominative use): "compatible with
  OpenThrottle", "a plugin for OpenThrottle", "based on OpenThrottle", or
  discussing, reviewing, teaching, or reporting on the project.
- **Unmodified redistribution** of an official release, still identified as
  OpenThrottle, provided you do not imply that you are the origin of, or
  affiliated with, the project.

## Unacceptable use — requires written permission

- Using the Marks (or a confusingly similar name/logo) as the **name of your own
  product, service, company, or a hosted/commercial offering** — for example a
  competing "OpenThrottle Cloud" or "OpenThrottle Pro".
- Using the Marks in a way that **implies endorsement, sponsorship, or
  affiliation** with OpenThrottle or Matthew Scholta when none exists.
- Applying the OpenThrottle **name or logo to a modified or forked distribution**
  as if it were the official project (rename your fork).
- Registering the Marks (or confusingly similar terms) as a **domain name, social
  media handle, app-store listing, company name, or your own trademark**.
- Altering the logo, or using the Marks in a false, misleading, or disparaging
  manner.

## Requesting permission

For uses that fall outside "acceptable use", or if you are unsure, request
permission before using the Marks. Contact details will be published with the
final version of this policy.

## Reservation of rights

Matthew Scholta reserves all rights in the Marks. This policy may be updated as
the project and the trademark application evolve; the current version in the
repository governs.
