# openthrottle-cms

OpenThrottle content CMS (React Router, Vite). See [applications/openthrottle/README.md](../openthrottle/README.md) for Postgres, Redis, and API setup.

**Technology:**

- [React Router](https://reactrouter.com)
- [React](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com)
- [Vercel](https://vercel.com)

## Setup

From the monorepo root:

```bash
# 🔒 Create or update the environment variables
./scripts/environment.sh

# Run the application
pnpm nx run openthrottle-cms:dev
```
